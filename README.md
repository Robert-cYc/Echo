# Fluent Network Sentinel (Windows 11 Fluent UI 網路狀態監控工具)

一個基於 **PowerShell** + **WPF (XAML)** 與 **Windows 11 Fluent Design** 打造的現代化多目標即時網路狀態監控軟體。支援 **即時延遲走勢圖 (Sparkline)**、**獨立訊息迴圈常駐系統匣 (System Tray)**、**高對比動態指示燈圖示**、**Windows 11 原生通知**、**中英文雙語即時切換** 與 **智慧網段偵測**。

---

## ✨ 核心功能亮點

1. **📈 即時延遲走勢圖 (Sparkline) 與網路抖動率 (Jitter)**：
   - 4 張監控卡片均內嵌 **微型延遲波動折線圖**，動態呈現最近 300 次 Ping 的往返時間（RTT）變化趨勢。
   - 走勢圖依延遲高低動態變色（`<30ms` 活力青藍、`30~100ms` 警示黃、`>100ms` 橘紅、斷線紅點到底）。
   - 依據 RFC 3550 演算法即時計算 **Jitter（網路抖動率）**，精準掌握連線會議、VoIP 或連線遊戲的延遲穩定度。
   - **滑鼠懸停品質分級指南 (ToolTip)**：滑鼠移動至走勢圖或抖動指標時，自動彈出原生深色浮動視窗，詳細說明 Ping 延遲等級（極佳/良好/普通/爆 Ping）與 Jitter 抖動穩定度判讀標準，並隨中英文動態切換。

2. **📥 系統匣常駐 (System Tray) 與動態狀態圖示**：
   - 採用獨立 `System.Windows.Application` 訊息迴圈（`ShutdownMode = OnExplicitShutdown`），視窗縮小或關閉時背景持續運作，絕不異常終止行程。
   - **專屬 16x16 向量繪製高對比圖示**：依連線狀態動態切換指示燈號：
     - 🟢 **綠燈**：網路狀態正常
     - 🔴 **紅燈**：偵測到目標異常斷線
     - ⚪ **灰燈**：手動暫停監控
   - **滑鼠左鍵**：點擊圖示立即喚回視窗並置頂顯示。
   - **滑鼠右鍵**：彈出雙語功能選單（「顯示主視窗」、「暫停/繼續監控」、「結束程式」）。
   - 工具列提供 **「📥 縮至系統匣」** 快捷按鈕與 **「關閉時縮小至系統匣」** 核取方塊。
   - *提示：若在 Windows 11 工作列右下角未直接看到圖示，可點擊 **`^`（隱藏的圖示展開箭頭）**，亦可將其拖曳至外側常態顯示。*

3. **⚡ Windows 開機自動啟動 (Start with Windows)**：
   - 工具列內建 **「開機自動啟動」** 核取方塊，可隨時一鍵啟用或關閉。
   - 透過 Windows 原生登錄檔機碼（`HKCU:\Software\Microsoft\Windows\CurrentVersion\Run`）開機載入，不需系統管理員權限。
   - 開機自動啟動時採用 `-Startup` 靜默模式，程式直接常駐於系統匣背景持續監控網路，不彈出干擾主視窗。
   - 內建雲端硬碟虛擬磁區延遲重試機制，開機時若虛擬磁碟機尚未掛載會自動等待就緒後啟動。

4. **🔔 Windows 11 原生彈窗通知 (Toast / Balloon Notification)**：
   - 任一監控目標發生異常斷線時，立即彈出 Windows 11 原生警告通知：`⚠️ 網路斷線警報: [目標] 已失去連線！`
   - 目標恢復連線時，自動彈出恢復通知：`✅ 網路已恢復連線: [目標] 已重新連線成功！`
   - 視窗縮小常駐時，主動發送氣球提示，告知背景持續運作中。

5. **🌐 中英文即時雙語切換 (Bilingual Support)**：
   - 工具列右上角配備 **「🌐 English / 繁體中文」** 切換按鈕。
   - 一鍵即時更新所有視窗標題、卡片資訊、指標標籤（延遲/平均/極值/遺失率/抖動）、控制按鈕、系統匣選單與即時日誌語系，完全無須重啟程式。

6. **🔍 智慧多網卡掃描與網段選取 (Multi-Adapter Smart Discovery)**：
   - 啟動與點擊 **「🔄 重新辨識網段」** 時，重新枚舉全機所有作用中（Status = Up）之網路卡（實體 Wi-Fi、乙太網路線、虛擬介面卡）：
     - 🌐 **有上網能力時**：自動追蹤對外路由與連網連線設定檔，優先抓取具備 Internet 連線能力的網卡網段（標註 `[🌐 Internet]`），精確追蹤預設閘道與網段活躍設備。
     - 📡 **無外網時（純區網 / 離線實驗環境 / 獨立交換機）**：自動執行區網活躍度權重評分（實體硬體網卡優先 +50 分、具備閘道 +40 分、同網段可通訊 ARP 鄰居數量最多 +60 分、收發流量 +10 分），自動選取通訊最活躍之區域網卡網段（標註 `[📡 Local LAN]`），智慧排除無流量或 host-only 之虛擬網卡。
   - 精確取得本機 IP（如 `192.168.1.227`）、子網路遮罩長度（如 `/24`）、網段範圍（如 `192.168.1.0/24`）與預設閘道（如 `192.168.1.1`）。
   - 自動透過鄰近設備快取（ARP Neighbor）找出同網段中的實體活躍設備（如 `192.168.1.185`），自動填入作為 Local 監控目標。
   - 頂部設有 **「目前網路網段資訊列」** 與 **「🔄 重新辨識網段」** 按鈕，切換 Wi-Fi 或插拔網路線時一鍵立即重新掃描所有網卡並自動切換。

7. **🎯 4 組目標同步即時監控 (3 組 Local 均可手動修改)**：
   - 🌐 **外網狀態 (WAN)**：持續偵測 `www.google.com` 網際網路連線品質。
   - 📡 **區域設備 #1 (GATEWAY)**：自動抓取當前網段的預設閘道/路由器（如 `192.168.1.1`）。
   - 💻 **區域設備 #2 (SUBNET #2)**：同網段內已偵測到的活躍設備（如 `192.168.1.185`，或網段 `.2`）。
   - 🖥️ **區域設備 #3 (SUBNET #3)**：本機實體網卡 IP（如 `192.168.1.227`）或網段 `.254`。
   - 3 組區域目標均具備獨立輸入框，可隨時輸入新 IP 按下 **Enter** 或點擊 **「套用」** 立即生效。

8. **🧹 日誌滿 100 筆自動清空 (Auto-Clear Log at 100 Entries)**：
   - 即時活動日誌區塊自動計數（`0 ~ 100 筆`）。
   - 達到 **100 筆上限** 時，程式會自動清空日誌快取並留下清理提示，重新從第 1 筆開始記錄，避免長時間運行佔用多餘記憶體。

9. **🎨 Windows 11 Fluent UI 深色主題**：
   - 深色 Mica 主題配色風格（`#181818` / `#242424`）。
   - 調用 Windows 11 DWM API 實現原生深色標題列與圓角視窗（Window Corner Preference）。
   - 「偵測間隔」下拉選單全面優化為黑底白字風格。
   - 非同步 Background Task + UI Dispatcher 進行並行 Ping，連線逾時亦不影響 UI 操作流暢度。

## 🚀 啟動方式

### 方法 1：專屬圖示捷徑啟動（最推薦）
在檔案總管中雙擊具備專屬雷達脈衝圖示的：
```text
Network Sentinel
```
*(已綁定專屬 Windows 11 Fluent 網路雷達脈衝圖示，點擊直接無黑視窗啟動)*

### 方法 2：批次檔一鍵啟動
直接在檔案總管中雙擊：
```cmd
Start-NetworkSentinel.bat
```
*(會以無黑視窗背景模式啟動 Fluent UI 介面)*

### 方法 3：使用 PowerShell 命令列啟動
```powershell
powershell -ExecutionPolicy Bypass -File .\NetworkSentinel.ps1
```

## 🛠️ 檔案結構說明

- `NetworkSentinel.ico`：專屬高解析應用程式圖示（包含 256x256、64x64、48x48、32x32、16x16 尺寸，現代深色雷達圓盤與實時連線脈衝電波設計）。
- `Network Sentinel.lnk`：原生 Windows 捷徑（已設定專屬雷達圖示，雙擊直接啟動）。
- `NetworkSentinel.ps1`：主程式碼（包含 Sparkline 走勢圖、GDI+ 16x16 系統匣動態圖示、應用程式高解析圖示綁定、Toast 通知、中英文切換、自動網段辨識、WPF XAML、DWM 深色樣式 API、4 目標非同步 Ping 引擎、UI 事件處理）。
- `Start-NetworkSentinel.bat`：快速啟動腳本，自動繞過執行原則並隱藏背景終端機視窗。
- `README.md`：完整架構與功能說明文件。
