# Fluent Network Sentinel (Windows 11 Fluent UI 網路狀態監控工具)

一個基於 **PowerShell** + **WPF (XAML)** 與 **Windows 11 Fluent Design** 打造的現代化多目標即時網路狀態監控軟體。支援 **即時延遲走勢圖 (Sparkline)**、**最小化至系統匣 (System Tray)**、**Windows 11 原生通知**、**中英文雙語即時切換** 與 **智慧網段偵測**。

---

## ✨ 核心功能亮點

1. **📈 即時延遲走勢圖 (Sparkline) 與網路抖動率 (Jitter)**：
   - 4 張卡片均內嵌 **微型延遲波動折線圖**，動態呈現最近 30 次 Ping 的往返時間變化。
   - 走勢圖依延遲高低動態變色（<30ms 活力青藍、30~100ms 警示黃、>100ms 橘紅、斷線紅點到底）。
   - 即時計算 **Jitter（網路抖動率）**，精準掌握線上會議或連線遊戲的延遲穩定度。

2. **📥 最小化至系統匣 (System Tray) 與背景常駐**：
   - 支援最小化或點擊右上角「關閉」時自動隱藏到工作列右下角系統匣圖示。
   - 工具列提供 **「📥 縮至系統匣」** 按鈕與 **「關閉時縮小至系統匣」** 選項。
   - 系統匣圖示左鍵點擊立即喚回視窗，右鍵支援繁中/英文選單（顯示視窗、暫停/繼續、結束程式）。

3. **🔔 Windows 11 原生彈窗通知 (Toast / Balloon Notification)**：
   - 任一目標發生異常斷線時，右下角彈出 Windows 11 原生警告通知：`⚠️ 網路斷線警報: [目標] 已失去連線！`
   - 目標重新連線成功時，自動彈出恢復通知：`✅ 網路已恢復連線: [目標] 已重新連線成功！`

4. **🌐 中英文即時雙語切換 (Bilingual Support)**：
   - 工具列右上角配備 **「🌐 English / 繁體中文」** 切換按鈕。
   - 一鍵即時更新所有視窗標題、卡片資訊、指標標籤（延遲/平均/遺失率/抖動）、控制按鈕、托盤選單與即時日誌語系，無須重啟。

5. **🔍 智慧偵測當前網路網段 (Auto Subnet Discovery)**：
   - 啟動時自動分析目前作用中的網路卡（如 `Wi-Fi` 或 `以太網`）。
   - 精確取得本機 IP（如 `192.168.1.227`）、子網路遮罩長度（如 `/24`）、網段範圍（如 `192.168.1.0/24`）與預設閘道（如 `192.168.1.1`）。
   - 自動透過鄰近設備快取（ARP Neighbor）找出同網段中的實體活躍設備（如 `192.168.1.185`），自動填入作為 Local 監控目標。
   - 頂部設有 **「目前網路網段資訊列」** 與 **「🔄 重新辨識網段」** 按鈕，切換網路時一鍵立即重整。

6. **4 組目標同步即時監控 (3 組 Local 均可手動修改)**：
   - 🌐 **外網狀態 (WAN)**：持續偵測 `www.google.com` 連線品質。
   - 📡 **區域設備 #1 (GATEWAY)**：自動抓取當前網段的預設閘道/路由器（如 `192.168.1.1`）。
   - 💻 **區域設備 #2 (SUBNET #2)**：同網段內已偵測到的活躍設備（如 `192.168.1.185`，或網段 `.2`）。
   - 🖥️ **區域設備 #3 (SUBNET #3)**：本機實體網卡 IP（如 `192.168.1.227`）或網段 `.254`。
   - 3 組區域目標均具備獨立輸入框，可隨時輸入新 IP 按下 **Enter** 或點擊 **「套用」**。

7. **🧹 日誌滿 100 筆自動清空 (Auto-Clear Log at 100 Entries)**：
   - 即時活動日誌區塊自動計數（`0 ~ 100 筆`）。
   - 達到 **100 筆上限** 時，程式會自動清空日誌快取並留下清理提示，重新從第 1 筆開始記錄，避免長時間運行佔用多餘記憶體。

8. **Windows 11 Fluent UI 深色主題**：
   - 深色 Mica 主題配色風格（`#181818` / `#242424`）。
   - 調用 Windows 11 DWM API 實現原生深色標題列與圓角視窗（Window Corner Preference）。
   - 「偵測間隔」下拉選單全面優化為黑底白字風格。
   - 非同步 Background Task + UI Dispatcher 進行並行 Ping，連線逾時亦不影響 UI 操作。

## 🚀 啟動方式

### 方法 1：一鍵啟動（推薦）
直接在檔案總管中雙擊：
```cmd
Start-NetworkSentinel.bat
```
*(會以無黑視窗背景模式啟動 Fluent UI 介面)*

### 方法 2：使用 PowerShell 命令列啟動
```powershell
powershell -ExecutionPolicy Bypass -File .\NetworkSentinel.ps1
```
