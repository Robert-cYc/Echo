# Fluent Network Sentinel (Windows 11 Fluent UI 網路狀態監控工具)

一個基於 **PowerShell** + **WPF (XAML)** 與 **Windows 11 Fluent Design** 打造的現代化多目標即時網路狀態監控軟體，支援 **中英文 (繁體中文 / English) 即時雙語切換**。

---

## ✨ 核心功能亮點

1. **🌐 中英文即時雙語切換 (Bilingual Support)**：
   - 工具列右上角配備 **「🌐 English / 繁體中文」** 切換按鈕。
   - 一鍵即時更新所有視窗標題、卡片資訊、指標標籤（延遲/平均/遺失率）、控制按鈕與即時日誌語系，無須重啟應用程式或中斷 Ping 偵測。

2. **🔍 智慧偵測當前網路網段 (Auto Subnet Discovery)**：
   - 啟動時自動分析目前作用中的網路卡（如 `Wi-Fi` 或 `以太網`）。
   - 精確取得本機 IP（如 `192.168.1.227`）、子網路遮罩長度（如 `/24`）、網段範圍（如 `192.168.1.0/24`）與預設閘道（如 `192.168.1.1`）。
   - 自動透過鄰近設備快取（ARP Neighbor）找出同網段中的實體活躍設備（如 `192.168.1.185`），自動填入作為 Local 監控目標。
   - 頂部設有 **「目前網路網段資訊列」** 與 **「🔄 重新辨識網段」** 按鈕，切換網路時一鍵立即重整。

3. **4 組目標同步即時監控**：
   - 🌐 **外網狀態 (WAN)**：持續偵測 `www.google.com` 連線品質。
   - 📡 **區域設備 #1 (GATEWAY)**：自動抓取當前網段的預設閘道/路由器（如 `192.168.1.1`）。
   - 💻 **區域設備 #2 (SUBNET #2)**：同網段內已偵測到的活躍設備（如 `192.168.1.185`，或網段 `.2`）。
   - 🖥️ **區域設備 #3 (SUBNET #3)**：本機實體網卡 IP（如 `192.168.1.227`，驗證本機連線協定棧正常）或網段 `.254`。

4. **3 組 Local IP 均允許獨立動態修改**：
   - 每一組區域設備均有專屬的「目標 IP 輸入框」與「套用」按鈕。
   - 修改後按下 **Enter** 或點擊 **「套用」** 立即切換偵測目標，並自動重置該目標的統計數據。

5. **完整連線指標儀表板**：
   - **即時延遲 (Latency)**：支援顏色分級標示（<30ms 青藍色、30~100ms 琥珀黃、>100ms 橙色、斷線紅色）。
   - **平均延遲 (Avg)**：即時統計平均往返時間。
   - **最小 / 最大延遲 (Min / Max)**：極端值追蹤。
   - **封包遺失率 (Packet Loss %)**：計算 `Lost / Sent` 與遺失次數。
   - **最後回應時間**：精準標註最近一次收到封包的時間。

6. **Windows 11 Fluent UI 設計**：
   - 深色 Mica 主題配色風格（`#181818` / `#242424`）。
   - 調用 Windows 11 DWM API 實現原生深色標題列與圓角視窗（Window Corner Preference）。
   - Segoe UI Variable 字體與現代化按鈕、輸入框樣式、連線狀態徽章（Status Pill）。
   - **「偵測間隔」下拉選單全面優化為黑底白字風格**。
   - 支援卡片區域垂直滾動（ScrollViewer），在各類螢幕解析度下均能舒適呈現。

7. **實用輔助工具**：
   - **偵測間隔切換**：支援 1 秒、2 秒、3 秒、5 秒自由調整。
   - **暫停 / 繼續偵測** 與 **重置所有統計** 功能。
   - **斷線警報音效**：勾選後任一目標若發生異常斷線即時播放系統提示音。
   - **即時偵測日誌 (Activity Feed)**：自動滾動記錄最近 100 筆連線狀態，可一鍵清除。
   - **極致流暢不卡頓**：採用非同步 Background Task + UI Dispatcher 進行並行 Ping，連線逾時亦不影響 UI 操作。

## 🚀 啟動方式

### 方法 1：一鍵啟動（推薦）
直接在檔案總管中雙擊：
```cmd
Start-NetworkSentinel.bat
```
*(會以無黑視窗背景模式啟動 Fluent UI 介面)*

### 方法 2：使用 PowerShell 命令列啟動
```powershell
powershell -ExecutionPolicy Bypass -File .\NetworkSentinel.ps1
```
